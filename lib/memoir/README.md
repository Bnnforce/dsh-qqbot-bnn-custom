# memoir — 群回忆录模块

> R5.5 · 让机器人讲讲「这个群这周发生了什么」

## 这个模块是什么

把群聊历史变成一段**她说出口的故事**：

```
这 7 天群里一共说了 797 句话，20 个人参与。最热闹的是 21 点前后，
那会儿有 139 条。说话最多的是 Bnnforce、欣芷、三月的肥鱼。
聊得比较多的有「语音」「人格切」「爱莉希」「你好」。
```

## 快速开始

```
/回忆录          近 7 天（默认）
/回忆录 3        近 3 天
/回忆录 30       近 30 天（上限 90）
```

## 数据从哪来

```
{dataRoot}/.qqbot/msg-history/group_<群id>/<YYYY-MM-DD>.jsonl
```

由官方 `msg-history.ts` 维护（默认保留 7 天）。
**只读，绝不写/改/删**。

## 两层流水线

```
① clean.mjs    清洗（去 @提及 / 引用块 / 表情占位 / 注入标记 / 伪造身份）
      ↓
② stats.mjs    统计（总数 / 人数 / 时段 / 排行 / 关键词）
      ↓
③ narrate.mjs  叙事（LLM 优先 → 失败退模板）
```

## 为什么必须先清洗（实测）

不清洗直接做词频，结果全是噪声：

```
主人(164) 引用(70) 回复开(70) 头写(70) 再说话(70)
```

根因：消息里混着 `<@openid>`、`[引用...]`、`【表情: xx】`、
`★主人`（群友手打伪造）、`暂不能查看该消息内容`（平台占位）。

清洗后（真实群 1410 条 → 797 条有效）：

```
语音(30) 爱莉希(24) 人格切(19) 妈妈(12) 喵喵喵(10) 抽签(10)
```

## 两种叙事形态

| 形态 | 条件 | 说明 |
|---|---|---|
| **B. LLM 叙事** | 能拿到 `kernel.get('llm')` | 她的口吻、口语化、不念清单 |
| **A. 模板叙事** | LLM 不可用 | 纯数据填空，**保底永远有输出** |

### LLM 调用（已实证的路径）

扩展侧**没有** `ctx.llm` —— 实测能力包只有 35 个键，没有 llm。
唯一入口是 `kernel.get('llm')`（契约文档 `extension-contract.md:124`），
复用 `lib/shop/adapters/llm-host.mjs` 的现成封装。

⚠️ **实测约束**：`kernel.get('llm')` 在 **命令 handler / 定时任务**里能拿到，
在**卡片按钮回调**里拿不到 ⇒ 所以本期用命令而不是卡片。

## 配置

文件：`{EXT_DATA}/memoir-config.json`（缺省用默认值）

| 字段 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 总开关。false = 命令直接回「已关闭」，零 IO |
| `days` | `7` | 统计最近几天 |
| `maxOutputChars` | `300` | 输出字数上限 |
| `topPeople` | `5` | 发言排行取几人 |
| `maxKeywords` | `8` | 关键词取几个 |
| `llmEnabled` | `true` | 关掉就用纯模板 |
| `llmTimeoutMs` | `20000` | LLM 超时 |
| `minMessages` | `30` | 有效消息少于此值不生成 |
| `tz` | `Asia/Shanghai` | 时区 |

环境变量覆盖（测试隔离用）：
`BNN_MEMOIR_ENABLED` / `BNN_MEMOIR_LLM` / `BNN_MEMOIR_DAYS` /
`BNN_MEMOIR_MIN_MESSAGES` / `BNN_MEMOIR_MAX_CHARS` / `BNN_MEMOIR_TZ`

## 红线（改代码前必须读）

| # | 红线 | 原因 |
|---|---|---|
| 1 | **只读历史** | 绝不写/改/删 `msg-history` |
| 2 | **不写记忆** | 回忆录只发出去，不写入 `memory/`，否则污染对话上下文 |
| 3 | **输出不含 openid** | 隐私 |
| 4 | **不复述他人原话** | 只出统计与改写后的叙述 |
| 5 | **失败绝不抛** | 降级到模板，最差返回友好提示 |

## 失败原因与提示

| reason | 含义 | 提示 |
|---|---|---|
| `DISABLED` | 总开关关闭 | 回忆录功能已关闭。 |
| `NO_DATA` | 没有历史 / 没有消息 | 这个群还没有聊天记录 |
| `TOO_FEW` | 有效消息 < minMessages | 记录太少，过阵子再来 |
| `ERROR` | 其他异常 | 暂时生成不出来 |

## 已知限制

| # | 限制 | 说明 |
|---|---|---|
| 1 | 只看近 7 天 | 官方 `KEEP_DAYS=7`，更早的已被清理 |
| 2 | 关键词是字符 n-gram | 不是真正语义理解，会有碎片（已做子串让位优化）|
| 3 | 不含图片/语音内容 | 只统计条数，不解析媒体 |
| 4 | 昵称重名会合并 | 按昵称聚合，未按 openid 细分 |
| 5 | LLM 不可用时降级模板 | 模板较机械，但保证有输出 |
| 6 | 卡片回调拿不到 LLM | 所以本期用命令，不做卡片 |

## 扩展方式

### 想改输出风格？

改 `narrate.mjs` 的 `narrateTemplate()` 或 LLM 的 `system` 提示词。

### 想加统计维度？

1. 在 `stats.mjs` 的 `computeStats()` 返回值加字段
2. 在 `narrateTemplate()` 里用上
3. 补 `mock-memoir-stats.mjs` 断言

### 想改清洗规则？

改 `clean.mjs` 的 `NOISE_RULES` 数组（顺序敏感：越具体越靠前）。
**必须补对应的 `hasNoise()` 断言**。
