## 1. 症状表

| 症状 | 先查 | 大概原因 |
|---|---|---|
| **群里完全没反应** | 插件有没有正常加载？看 DSH 启动日志 / `~/.dsh/data/dsh-bnnbotbox/boot.log` | 插件本身没起来，不是扩展的事 |
| **某个命令没反应** | 命令是否被 @ 门控拦了？ | 群聊里斜杠命令默认也要 @ |
| **改了 `commands/` 不生效** | 重启了吗？ | commands **必须重启**，`/tools-reload` 不覆盖 |
| **改了 `hooks/` 不生效** | 重启了吗？ | 同上 |
| **改了 `inbound/outbound/tools` 不生效** | 发 `/tools-reload` 了吗？ | 这三层支持热重载 |
| **点卡片报「模块加载失败」** | `node scripts/sync-botplay.mjs`<br>`{dataRoot}/.qqbot-extensions/botplay/botplay-ext.log` 最后几行 | 运行时副本没同步，或缺 `lib/` 依赖树 |
| **卡片能开但按钮没反应** | `~/.dsh/qqbot-dispatch-diag.log` | 回调没注册 / 派发链没命中 |
| **点抽奖回「拿不到你的身份」** | `tools/` 里取群号的逻辑 | 真实回调 ctx **没有顶层 `peerId`**，群号在 `peer.groupId`；且单聊要早退 |
| **她的话被莫名改掉**（开头几个字没了 / `https:` 变 `//` / 换行被压平） | 出站链有没有清洗逻辑？看 `[清洗]` 日志 | 全局文本清洗规则过激 |
| **主动说话太频繁 / 完全不说话** | 发言预算状态 + 各功能自己的限频 | 见 §3 |
| **定时任务不跑** | `node scripts/doctor.mjs`、`{dataRoot}/.qqbot-extensions/data/` 下的状态 | 执行器没注册 / 引擎没接管 |
| **点歌没反应** | `node scripts/doctor.mjs` 看「曲库」 | 曲库目录没放歌（**不会自动建**） |
| **`/来张图` 没反应** | 同上，看「美图库」 | 素材没放 |
| **语音发不出去** | `silk-wasm` 装了吗？ | 依赖缺失，降级为文字 |

## 3. 主动说话相关的三个闸

本包有多个功能会「主动说话」，它们各有限频，还共用一道全局闸。**不说话时按这个顺序排**：

```
① 功能自己的开关       → 配置里 enabled
② 功能自己的限频       → 每群每天几次 / 多久一次
③ 全局发言预算         → 同一个群两次至少隔多久、一天最多几次
④ 装死窗               → 某时间段内不做
⑤ 外部条件             → 会话还活着吗（wakeTo 会失败）
```

`③ 全局发言预算` 是最容易忽略的：它**跨功能共享**，一个功能说了话，
另一个功能在同群就得让路（`speak-budget.json` 里能看到 `today` / `lastAt`）。

## 4. 「静默跳过」排查（最难查的一类）

| 层 | 静默跳过条件 | 怎么确认 |
|---|---|---|
| `inbound/` | 导出形态不是 `onInbound` / `onDecide` / 裸默认导出 | 用 `docs/扩展点速查.md` §7 的装载自检看 `skipped` |
| 任意扩展 | 顶层抛错 / 依赖 import 不到 | 手动 `node --check` + 手动 `import` 一遍 |
| `botplay/` | 文件在但依赖树不全 | `scripts/sync-botplay.mjs --check` |
| `tools/` | 缺 `name` 或 `run` | 同上 import 一遍看导出 |
| 任务中心任务 | 执行器没注册（如 `run()` 提前 return） | 任务中心自检 / 日志里「尚无执行器」 |

**核心判据：`node --check` 只证明语法；能证明「能跑」的只有真的 `import` 一遍。**
再往上一级是「真机点一遍」。

## 5. 平台侧问题（不是本包能修的）

| 报错 | 含义 | 怎么办 |
|---|---|---|
| `主动消息失败, 无权限` | 没有主动消息额度 / 权限 | 少主动发；插件侧有被动回复窗口，优先走被动 |
| `消息发送失败，机器人非群成员` | 机器人被移出群了 | 重新拉进群 |
| `40034126 无ark模板权限` | 想用 ark 卡片但没有模板权限 | 用 `msg_type=8` 图文卡片代替 |
| 频道/接口 4xx | QQ 官方接口语义 | 查官方 OpenAPI v2 文档 |
